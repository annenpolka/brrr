### 1. scarp — clock leftover (mutation-46)

**Primitive.** Two timestamps or two clock-cuts on stdin; emit which clock explains the gap. Filter. No spawn.

**Why it might not exist.** `time(1)` wraps. `uptime(1)` is since-boot folklore. `lapse` already named wall/machine/awake/proper — and buried the object under `Popen`. You cannot paste two `time.monotonic()` readings a timeout already stored. Python’s docs say `monotonic` is a machine clock. On Darwin it is `CLOCK_UPTIME_RAW`: **lid-close does not tick it.** Comparing wall to “monotonic” since boot is a day of sleep. The industry workaround is “NTP stepped.” That sentence is false on this laptop.

**DESTROYER** (mutate): `ntp=` is adjtime, not NTP; `classify_text` is `cuts[0], cuts[1]`; unlabeled ticks are a duration bag or the first eight fields; porcelain 0-fill round-trips REST→STEP; missing proper lets 22d awake beat 1d sleep.

**This judge.** The holes make it weirder, not weaker. A filter that had to name four clocks and still printed slew as `ntp=` is how you discover a fifth name. Peels (twixt/lurch stream, yaw SLEW, scree repeated keys) are mutations of a real object. Killing scarp because JSONL is a pair would throw away the Darwin fact.

Live, this host:

```
SLEEP  explains=machine  kind=host
  sleep        1d05h03m
  ntp           -7.354s
reason  host slept 1d05h03m (5% of coordinate)
note    time.monotonic() on Darwin is awake, not machine
```

`{cut; sleep 0.35; cut} | scarp` → **DILATE**, scarp spawned neither. `printf '1000\n1001\n'` → **REST**. `selftest 7/7`.

**§3 sentence.** A Unix filter that names the clock that owns a gap; Darwin monotonic is awake.
