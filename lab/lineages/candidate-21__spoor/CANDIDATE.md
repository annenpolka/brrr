# candidate-21 — spoor

## Primitive

Waitpid is not completion: a command's true end is filesystem+process quiescence, and the *wake* it leaves (late writes, leaked children, leftover paths, tests colliding on the same file, stale generated products) is a first-class, diffable object.

## Four primitives considered

1. **CI-reify** — emit the CI command matrix you have not run locally. *Discarded: conventional* (`act`, a justfile that mirrors `.github/workflows`).
2. **Hunk-to-tests** — map a git hunk to likely tests by identifier overlap. *Discarded: conventional* (coverage + `git grep`).
3. **spoor / command-wake** — implemented. Completion-as-quiescence + residue-as-object, including test-boundary FS collisions and generated-artifact staleness.
4. **Pipe-hang autopsy** — when a pipeline is killed, dump which stage's stdin is full, which stdout is empty, last bytes, process states. *Kept as a mutation, not this ship.* The more dogfoodable remaining primitive was (3).

## Why this might not exist

`time` reports duration. `strace`/`fs_usage` report syscalls (often root, never a queryable object). Test runners report pass/fail. `make` reports stale products if you wrote the Makefile. Nobody treats **the heap of files and children a command allocated into** as something you can wait on, diff, and blame on individual tests — and `waitpid` returning is widely mistaken for "the world stopped moving."

## Empirical transcript

### Before the first real-use improvement

`./spoor run --watch $OUT -- python3 fixtures/afterexit.py $OUT`

- `late.txt` **existed** after the command (git `??`).
- Report said `quiesce … (world already still)` and `late_writes: []`.
- Cause: default-watching cwd + the user's entire `TMPDIR` (`/var/folders/.../T`). FSEvents took longer to arm than the 100ms process. Zero `kind=fs` timeline events.

`./spoor inspect voidtrace`

- scanned 2273 files, **51 orphan-source** hits inside `.pnpm-store` (content-addressed blobs whose first bytes happened to match `generated from`).
- `Cargo.lock`-style `@generated by Cargo` parsed source token `by`.

kizu wrap with `--exact` matched 0 tests (`running 0 tests` / 489 filtered out).

### After

1. Do **not** watch cwd/TMPDIR by default. Watch `--watch` paths and `--sandbox-tmp`. Git porcelain + **mtime vs waitpid wall clock** is the bookend sensor that cannot miss a file that still exists.
2. Poll small watch roots even when fswatch is present. Snapshot at each parsed test-completion line; hash small files so same-size overwrites collide.
3. Prune `.pnpm-store`, lockfiles, AGENTS.md. Parse JSON `"source"` and `Source:` lines. Inherit declared source from parent directories.

## Surprises

- macOS FSEvents is useless if you point it at a large tree for a 100ms command. Bookend git+mtime outran the "live" watcher for the actual late write.
- Test-completion lines are printed *after* the test's writes. Snapshotting *on* the line races the next test's first write unless there is a gap; hashing plus a poll walker recovered collisions.
- voidtrace's `.generated.json` files omit the comment banner but carry `"source": "specs/main.pkl"` in the JSON. Sibling/parent inheritance plus JSON parsing turned 6 "undeclared" into FRESH.
- kizu unit tests using `tempfile::tempdir()` really do clean up. The interesting residue is the *absence* of residue.

## Failures

- `fswatch %P` (pid of writer) is empty on macOS FSEvents — cannot attribute writes to PIDs without DTrace/root.
- Parallel test runners (`cargo test` default threads) make boundary attribution best-effort. `--test-threads=1` is honest.
- Commands that hardcode `/tmp` ignore `--sandbox-tmp`.
- `inspect` cannot see `target/` / `node_modules/` unless `--include-caches` (intentionally; those trees are a firehose).
- Pipe-hang autopsy was not implemented (primitive 4).

## Suggested mutations

- Invert: `spoor replay report.json --fail-if late_writes` as a CI gate ("no aftershock, no leaked children").
- Per-test `TMPDIR` (not one sandbox for the suite) so collisions become inevitable to observe.
- Pipe-hang autopsy (primitive 4) as `spoor pipe -- a | b | c`.
- Watch `target/` as *aggregated bursts* ("rustc wrote 400 files in 1.2s") rather than path lists.
- `spoor inspect --freshness-gate` exit 1 on STALE/ORPHAN, composing with voidtrace/tenaoshi `spec-check`.

## Kill / keep

**Keep.** The interaction is memorable (`time`, but for the world the command left behind), it composed with git and JSON, and dogfood on voidtrace/kizu produced both a real bug (slow FSEvents, pnpm-store false orphans) and a real negative result (kizu tests leave no wake).
