# kiln

A generated artifact is a **claim about a source world**. kiln reconstructs the firing *lot* from headers, generator recipes, and imports, then reports whether the claim still holds — and whether siblings that were fired together have since **split**.

Not `ninja -d explain` (that needs a graph you wrote). Not `make` staleness. Not snapshot diffs. The graph is recovered from the artifacts themselves. Rebuild reasons are **content/git**, not mtime. mtime is only consulted to catch CLOCK: the filesystem would have called the file fresh.

## Install / run

Python 3.10+, stdlib only.

```bash
chmod +x ./kiln
./kiln --help
./kiln --selftest
./demo.sh
./kiln -C /path/to/repo
./kiln -C /path/to/repo why path/to/oracles_generated.test.ts
./kiln -C /path/to/repo --tsv
./kiln -C /path/to/repo --check    # exit 1 on DATED/SPLIT/ORPHAN
```

## Verdicts

| tag | meaning |
| --- | --- |
| FRESH | world bytes have not moved since this artifact last changed |
| DATED | a source, undeclared import, or generator changed since fire |
| SPLIT | siblings that claim the same recipe have different fire times |
| BLIND | a source import is not named in the `@generated` header |
| CLOCK | mtime would call it fresh; git/content would rebuild |
| DIRTY | the artifact has uncommitted changes |
| ORPHAN | declared source is missing |
| FORGED | generated-looking / DO NOT EDIT, no parseable recipe |
| BOUND | oracle bakes an absolute path or a timezone offset |

## Examples

### 1. Split oracle lot (relico)

Four test oracles plus `docs/SPEC.md` all claim `tools/spec-gen.ts` ← `specs/notifier.pkl`. Git is clean. Tests pass. kiln:

```
[spec-gen.ts←notifier.pkl] SPLIT BLIND  fire 2026-07-20 19:43 .. 2026-07-28 10:18
  DATED,SPLIT,BLIND  tests/unit/oracles_generated.test.ts   fired 2026-07-20
  DATED,SPLIT,BLIND  tests/e2e/oracles_generated.e2e.ts     fired 2026-07-20
  SPLIT,BLIND        tests/renderer/oracles_generated.spec.ts fired 2026-07-28
  SPLIT,BLIND        docs/SPEC.md                           fired 2026-07-28
```

`./kiln why tests/unit/oracles_generated.test.ts` names the rebuild reasons: `specs/notifier.pkl`, undeclared `specs/patterns.pkl`, and `tools/spec-gen.ts` all changed since this oracle last moved.

### 2. In-progress regen (tenaoshi)

Working-tree dirty spec **and** dirty `OraclesGenerated.swift`. kiln also pulls headerless `contracts/testcases/*.json` from the generator's output list. One lot, BLIND to `patterns.pkl`.

### 3. Deep import world (voidtrace)

Headers say `Generated from specs/main.pkl`. kiln walks 50+ pkl imports and reports `docs/generated/CONTRACTS.md` (fired 2026-08-02) SPLIT from siblings fired 2026-08-20, with content reasons for the pkl files that actually changed.

## Why this is not make

make/ninja need a declared graph. These repos have `@generated by … from …` comments and `just spec-gen`. Git status is clean while unit oracles and the spec live eight days apart. kiln's object is the **lot**, not a target.
