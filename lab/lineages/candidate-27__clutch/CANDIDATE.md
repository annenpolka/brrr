# candidate-27 — clutch

## Primitive

A generated file's **receipt** (the parent, stamp, generator, machine it
already claims) is a first-class object. Files that cite the same parent are
a **clutch** — one generation event git never recorded. The verb is: cross-
examine the testimony, then say whether the eggs were re-laid together.

## Why this might not exist

`ninja -d explain` asks the build graph why a target rebuilt. `make` compares
mtimes. `just spec-check` regenerates and diffs. None of them read the
**colophon the artifact already carries** (`Generated from specs/main.pkl`,
`sourceFingerprint`, `正本は …`, `@generated by tools/spec-gen.ts from …`)
and join siblings by that testimony.

The recurring annoyance: a spec-gen run that rewrote `SPEC.md` but not
`oracles_generated.rs`, or a generated doc whose bytes are stable so git
never retouches it while 28 sibling files move. `spec-check` is green.
The lot is still ragged.

## Four primitives considered

1. **clutch** — generation receipts as testimony; lots that later split.
   **Implemented.**
2. **spoil** — oracle freshness: age of an expected value measured in
   mutations of the code it watches. Unusual; not implemented.
3. **habitat** — implicit machine/env requirements extracted from tests.
   **Discarded as conventional** (portability linters, Docker, Nix).
4. **sundial** — header-time vs commit-time vs mtime vs generator-mtime.
   **Discarded as conventional** (`stat`, `make -d`, `ninja explain`).

Not leftover names, not ghosts of deleted identifiers, not format inversion,
not copy detection, not path-conditions, not call protocols, not wait-for
graphs.

## How to run

From this worktree root:

```bash
./clutch --help
./demo.sh
./clutch --selftest
./clutch -C /path/to/repo
./clutch -C /path/to/repo --tsv
./clutch -C /path/to/repo --json
./clutch --explain docs/generated/SPEC.md
./clutch --locks   # include Cargo.lock / pnpm-lock as receipts
```

Python 3.10+ and `git`. Stdlib only. `./clutch` is the CLI.

## Surprises

- The stamp on VoidTrace generated files is a hash of the **parsed spec IR**,
  not of `specs/main.pkl` bytes. Testimony is in a different currency than
  the cited parent file. `currency=die` vs `currency=byte`.
- Git age 28 on `AI_UX.md` is not "the file is wrong" — the generator keeps
  emitting the same bytes, so git never retouches it. COLD ≠ STALE.
- Dirty working-tree parent is a real NOW signal and also a footgun: it
  paints the whole clutch STALE and hides the ragged members.

## Failures

- Default walk of voidtrace is unusable because `.pnpm-store` files say
  "generated".
- Prose files (justfile, AGENTS.md, spec-gen.ts, ARCHITECTURE.md, .gitignore)
  match generation vocabulary without being receipts.
- Stamp-only JSON manifests do not join the clutch they belong to.
- `GENERATED.md` already names the parent of a whole package and is ignored.

## Suggested mutations

- Treat golden `*.expected.json` / snapshot oracles as a second clutch
  object (spoil).
- `--regen` dry-run: run the cited recipe and re-assay.
- Watch `just spec-gen` and emit a clutch diff as the generation event.
- Machine/toolchain receipts when generators start writing them.

## Kill / keep

Keep. The object (a generation lot reconstructed from artifact testimony)
is not `ninja -d explain` and not `spec-check`. Relico's 0/1/4 lag and
VoidTrace's 28-commit cold sibling are things a developer would want
tomorrow, without regenerating anything.
