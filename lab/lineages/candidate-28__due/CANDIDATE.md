# candidate-28 — due

## Primitive

A program has an **environment ABI**. `due` harvests the names it actually consults and joins two environments (or a source tree and a shipped image) on *just those names*.

The object is not "the process environ" and not "every ALLCAPS string in a binary". It is **the owed set**, with evidence (`call` / `shell` / `string`) and a locus.

## Four primitives considered

1. **due** — env ABI of a binary/script/tree; env-diff and packed emit restricted to that ABI. **Implemented.**
2. **tale** — narrative-split of a commit by symbol/import coupling. Discarded: `git add -p`, `git-revise`, stacked-PR splitters already occupy the verb.
3. **mint** — promote last N shell commands to a parameterized named verb. Discarded: `alias` / `fc` / `just` exist in spirit; generalization is a macro recorder, not a new object.
4. **stale** — generated-file freshness vs *claimed* spec (undeclared Makefile edges, `// Code generated by`, hand-edits). Leftover mutation; pinch already discarded declared why-rebuild as `ninja -d explain`.

Not leftover-name hunting, not inverse printf, not a wait-for graph.

## Why this might not exist

The recurring workflow: a binary works on your laptop and dies in CI.

1. `env | sort > local.txt`
2. steal a CI env dump
3. `comm -3` the two files — 200 lines of `TERM` / `HOMEBREW_*` / `LC_*` noise
4. `strings ./server | grep '^[A-Z_]*$'` — is `DATABASE_URL` in there or is that a log level?
5. `rg getenv` / `rg os.environ` / `rg env::var` / `rg process.env` across languages
6. guess which of the remaining names the process actually reads
7. hand-write a `.env` to ship

`ldd` answers "what libraries". Nothing answers "what environment". `direnv` and dotenv linters check files against each other, not against the program. `strace -e getenv` needs a run (and on macOS, SIP). `due` is the static join.

## Empirical transcript

### Before the improvement (v0.1: isolated C-strings only)

Ugly fixture already worked (Python AST including `KEY = "DUE_CONST"` aliases and ignored stores, Rust `env::var` in a path with spaces, Japanese `計画.sh`, `process.env`, skip `node_modules` / dotfiles, `.env.example` join → `STALE_EXAMPLE` / `UNDOCUMENTED`, packed `--emit`, ABI round-trip, exit 1 on DIFF).

Binary harvest did not. A 40-byte C program `getenv("DUE_FIXTURE_C")` compiled on arm64 Mach-O to:

```
…\xd6 DUE_FIXTURE_C \x00 HOME \x00
```

`HOME` was a clean cstring. `DUE_FIXTURE_C` sat against a code byte, so NUL-split never produced an all-printable chunk. `due --names --app tiny.bin` missed the only application name.

kizu was worse. `strings target/release/kizu | grep KIZU_` is one printable run:

```

Rust packed every env literal against its neighboring path/string. Isolated-cstring harvest of the release image returned 16 compiler fragments (`D_0`, `T_0`, `TOTAL_COUNT`) and **zero** `KIZU_*`. Source harvest of `kizu/src` returned the real ABI:

```

`due git` against zsh's `which git` (a function) exploded. `shutil.which` finds `/opt/homebrew/bin/git`; `/usr/bin/git` on this Mac is a stub with no `GIT_*` strings.

### After the improvement (v0.2)

- Printable runs + prefix/suffix peel for packed rodata (`KIZU_CONFIG` | `XDG_CONFIG_HOME`).
- Needle search: a source-owed name is in the image if it appears as bytes followed by a non-token, a new `PREFIX_`, or a Titlecase word (`KIZU_STATE_DIR` + `Library/…`).
- `--vs-program`: source ABI ⋈ image ABI (`BOTH` / `LEFT_ONLY` / `RIGHT_ONLY`).
- `--app` + `is_likely_env_name` so image-only rows are runtime env (`RUST_BACKTRACE`) not unicode tables (`BITSET_CANONICAL`). Trim `KIZU_STATE_DIRL` glued to `Library`.

## Dogfood targets

- `fixtures/ugly` (spaces, `計画.sh`, `node_modules`, Python store-vs-load, compiled C, packed `.bin`)
- kizu `src/` + `target/release/kizu`
- Homebrew `git` (`/opt/homebrew/bin/git`)
- Homebrew `python3` (52k stub; see Failures)
- `./due` itself (call-evidence ABI is empty: it copies `os.environ`, it does not `getenv("FOO")`)

## Surprises

- Rust env literals are **not** C strings. `ldd`-style string table walks silently miss the entire application ABI.
- `KIZU_STATE_DIRLibrary/Application Support/kizu` is one run: the env name butts against a Titlecase path, not another `PREFIX_`.
- `TMUX` is the only kizu-owed name this shell pays. Attach detection is live; every `KIZU_*` override is unpaid. That is the packed-env story: `--emit` produced a one-line file.
- `due python3` follows the symlink to a 52k Mach-O stub. `PYTHONHOME` lives in libpython. Unlike `ldd`, `due` does not yet walk the load image.
- A libc prefix of `""` (from `__CF_USER_TEXT_ENCODING`.split) became `"_"` and shredded packed strings at every underscore. First-segment length ≥ 2 is load-bearing.

## Failures

- Image harvest still emits a handful of compiler tokens that look like env (`BITSET_CHUNKS_MAP`, `EMOJI_MODIFIER_LEAF`, `SERVICE_STATUS_HANDLE`). `--loose` keeps more; `--app` is not a proof.
- Homebrew `python3` / framework stub: 0 names. Need dylib walking.
- macOS `--vs-pid` uses `ps eww` KEY=VAL tokens; `/proc/PID/environ` is Linux-only and honest.
- Shell `$FOO` treats every `UPPER_SNAKE` expansion as owed, including script-local `export`.
- `due git` from a zsh interactive `which` can be passed a function body; the CLI uses `PATH` (`shutil.which`), which is the right Unix object.

## Suggested mutations

- **ldd-for-env of the load image**: walk `otool -L` / `ldd` and harvest each dylib. Makes `due python3` true.
- **`--trace`**: actually run the program under a getenv interposer and union dynamic names with the static ABI (`DUE` vs `LATENT`).
- **`stale`**: claimed generation lineage vs spec (the discarded fourth primitive).
- **CI YAML → env map**: parse GitHub Actions `env:` / `environment:` and join as `--vs` without a dump file.
- Tighten `RIGHT_ONLY` with a denylist of unicode/Mach-O section vocabularies.

## Kill / keep

**Keep.** The owed set is a missing Unix column. Source harvest is already useful tomorrow (`due --app src --vs .env --example .env.example`). The packed-rodata / source⋈image join is the strange part, and it is not done: dylib walking is the obvious next hour.
