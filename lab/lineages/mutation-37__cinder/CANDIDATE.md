# mutation-37 — cinder

## Primitive

Leftover **claims** a diff made false, but a regenerated dest file is **ash, not a believer**.

A *fact* is a typed bound name/value, rename, or polarity flip from a unified diff (ember's extractor). An afterimage in docs/tests/source/config is a leftover *claim* (exit 1). An afterimage in `generated/`, `oracle/`, lockfile-regenerated dest, `*.generated.*`, or a `@generated` banner is a **cinder**: leftover *build*. Exit `0` clean, `1` leftover *claims* (not cinders), `2` error. `--include-generated` prints ash without changing the exit.

Parents: **zanei** (candidate-07) skipped `vendor/`/`dist` and treated `generated/` as a believer. **nagori** (reimpl-03) same hole. **ember** (mutation-32) typed facts (full version tokens, calendar month is not integer 10, JSON keys, polarity needs a same-line name) and still failed: dest `generated/` scored like a forgotten claim. DESTROYER_ZANEI: a regenerated oracle is leftover *build*, not leftover *claim*.

## Why this might not exist

`rg` finds a token. `git grep` finds it at a revision. Neither knows that *this diff* made `timeout: 10 → 30` false. zanei/ember answer "what else still believes the old fact?" and then treat a regenerated `const MAX_RETRIES = 3` the same as a README sentence. Adding `generated/` to `SKIP_DIRS` would hide it the way `vendor/` is hidden — a leftover *build* would become invisible, not classified.

The missing status is **cinder**: dest ash you can see (`--include-generated`) that must not fail a linter.

## How to run

From this worktree root (Python 3.10+, `git` on `PATH`, no other deps):

```bash
chmod +x ./cinder ./demo.sh
./cinder self-test
./demo.sh                 # exits 0; fixtures + gold kizu/sitbone if present
./cinder --help
./cinder -C <repo>        # HEAD → worktree
git diff A B | ./cinder --diff - -C <repo>
git diff A B | ./cinder --diff - -C <repo> --include-generated
```

## Surprises

- Ember's `.lock` suffix skip was not a theory of lockfiles. It was vendor-shaped invisibility. Un-skipping without reclassifying as config made Cargo.lock *disappear twice*: once as skip, once as a 40-point code miss.
- `OraclesGenerated.swift` does not live under `oracle/` or `generated/`. Filename `*Generated` plus `@generated` banner is how a regenerated test oracle actually looks.
- Voidtrace leftover *claims* after a later worktree live in `docs/execplans/`; leftover *build* lives in `docs/generated/`. Same noun (`version`, hashes), different status.

## Failures

- No language parser. Historical trees do not recurse nested repos. Japanese bindings still do not parse (`タイムアウト = 10` is not a fact; leftover Japanese of an *English* fact still matches via alias). Fullwidth `１０` is not `10`.
- Two packages named `version` are one noun. kizu `Cargo.lock` ash is three `version = "0.3.0"` lines from *dependencies*, not the crate. They are correctly not leftover *claims*; they are still coarse ash.
- Size-cap omit is still silent. A 2 MB leftover README would look clean.
- Banner is first-eight-lines only. A generated file whose banner is buried still scores as a believer unless the path looks generated.
- `vendor/` stays skip-invisible. That is still the DESTROYER hole for vendored copies; cinder did not promote vendor to ash.

## Suggested mutations

- Workspace identity so `pkg_a` 0.3.0→0.7.0 does not accuse `pkg_b` (or three unrelated `Cargo.lock` lines).
- `cinder blame <path>:<line>`: invert the verb — given a leftover claim, show the diff that falsified it. Ash would answer "regenerate", not "edit".
- Size-cap omit must warn (ember already flagged this).
- Learn generated-ness from the repo (`just spec-gen`, `.gitattributes linguist-generated`) instead of a directory/banner table.

## Kill / keep

**Keep.** The object is still leftover *claims*. The flipped assumption is dest status: regenerated afterimages are cinders, not linter failures. Gold kizu plugin.json and sitbone CLAUDE.md still come out. October is not timeout 10. JSON-only `plugin version 0.3.0` still comes out. `generated/` is no longer a believer.
